Roles And Access

Create roles, tick what each can do, which are active, and which need two-factor sign in. Changes save as soon as you make them. Access by user comes later, inside the limit of the role.

The System Admin role is built in. It always has full access and cannot be renamed, deleted or reduced, so you can never lock yourself out. Only its two-factor switch can be changed. Every other role, including the ones that came with the system, can be renamed, and deleted when no user has it.
