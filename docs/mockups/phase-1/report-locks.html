Roles And Access

Create roles, tick what each can do, and lock or unlock reports and dashboard cards. Changes save as soon as you make them.

The Access tab is the role and feature grid you already have. Reports and dashboard cards are not in it any more. They have their own locks on the next tab.

A lock hides the figures. People still see the report or card in its place, with a message that it is locked. The System Admin is always open and cannot be locked. Locking is by role here. To lock one person inside a role, use the Access section on that person's Edit User screen.
