Reset Password

Set a temporary password for Sample Accounts One. They must change it the next time they sign in. For a cashier this resets the PIN instead.

Share it with the user in person or by phone. It is shown only now.

Deactivate User?

Sample Cashier One will be signed out and will not be able to sign in. Their history stays in the records. You can activate them again later.

Activate User?

Sample Cashier Two will be able to sign in again with their current password or PIN.

Reset Two-Factor?

The user will be asked to set up their authenticator app again the next time they sign in. Use this when they lose or change their phone.
